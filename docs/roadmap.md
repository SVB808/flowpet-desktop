# Roadmap

## M0 — runnable engineering MVP

- Windows foreground capture
- local SQLite storage
- segment aggregation
- rule classification
- Ollama + OpenAI-compatible classifier
- pet state window
- adaptive nudges
- recoveries
- quests
- first-run privacy consent
- exact-context correction memory
- 7-day raw-sample cleanup
- intentional-break state
- NSIS CI build

## M1 — private alpha

- per-app privacy exclusions
- configurable raw-sample retention
- correction-management UI
- browser origin enrichment via opt-in local companion extension
- model payload preview
- signed Windows installer
- crash-safe migrations and DB backup/export

## M2 — useful daily driver

- weekly focus/recovery insights
- quest personalization from 2+ weeks of history
- quiet hours and calendar-aware meetings
- pet theme system with original assets
- autostart controls
- updater channel
- accessibility pass and keyboard navigation

## M3 — public beta

- privacy threat-model review
- installer reputation/signing work
- telemetry off by default; explicit opt-in diagnostics
- export/import
- performance profiling on low-memory laptops
- macOS capture adapter after Windows stability
