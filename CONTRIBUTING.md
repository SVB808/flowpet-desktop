# Contributing

FlowPet is intentionally not a clone of any existing focus tracker. Contributions should preserve the project's independent visual language, recovery-first behavior, local-first privacy defaults, and provider-neutral AI boundary.

Before a feature is merged, ask:

1. Does it collect less data than the obvious implementation?
2. Can it fail without blocking the user's work?
3. Does it treat model output as advisory rather than authoritative?
4. Can a user correct it?
5. Can the behavior be tested deterministically without an LLM?
